## Project

Papertrail is a Go CLI application, module `zeleniy.spb.ru/papertrail`, built with [Cobra](https://github.com/spf13/cobra). It indexes files (text, PDF, etc.) and searches over them, exposed as console subcommands. A background daemon is planned as a later evolution once the CLI tools work.
